# How to Use Memory Tune-Up

This skill runs a guided interview that builds a memory profile of you, so your
AI gives advice that fits your real life instead of generic answers. Here is
how to set it up and run it.

There are two ways to use it. Pick the one that matches your setup.

---

## Option 1: Install the skill file (recommended)

Use this if your AI app supports adding skills or capabilities.

1. Download `memory-tune-up.skill` from this folder.
2. In your AI app, open Settings and look for the Skills or Capabilities
   section.
3. Upload or add the `memory-tune-up.skill` file.
4. Start a new chat and say: "run memory-tune-up" or "do the memory interview
   with me."

The skill will take it from there.

---

## Option 2: Paste the skill text (works anywhere)

Use this if you can't install a skill file.

1. Open `SKILL.md` from this folder.
2. Copy everything in it.
3. Paste it into either:
   - a project's custom instructions, if your AI supports projects, or
   - directly into a new chat, followed by: "Please follow these instructions
     and run this interview with me."

This works in almost any AI chat tool.

---

## Before you start: a quick privacy step

This interview builds a detailed personal profile of you. Before you begin,
turn off model training so your answers aren't used to train the AI.

In Claude:
1. Click your name or profile to open settings.
2. Go into Settings.
3. Open the Privacy section.
4. Under preferences, find "Help improve Claude" and turn it off.

If you use a dictation tool like Wispr Flow to talk to your AI, do the same
there: open its settings and turn off anything about using your dictation or
transcripts to improve the product. Your spoken answers are just as personal as
typed ones.

Menu labels move around. If something isn't where these steps say, look for the
nearest equivalent.

---

## Running the interview

- It's about thirteen questions, usually twenty to thirty minutes.
- The skill asks one question at a time and reflects back what it hears.
- If a question is hard to answer, say so. It will come at it from another
  angle. Don't skip, let it help you.
- At the end, you get a summary to review. Nothing is saved until you approve
  it. Cut anything that feels too personal to keep.
- For memory that lasts and shows up in all your future chats, run this in a
  normal chat, not inside a project folder or workspace.

## Do it again

People change. Run this every three to six months and update what's stale. The
skill will offer to help you set a reminder.
