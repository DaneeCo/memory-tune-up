# Memory Tune-Up

A guided interview that teaches your AI who you actually are.

Most people start every AI conversation from zero. The AI has no idea what you
do, how you decide, what you're building, or what you can't stand. So it hands
back generic advice, and most people assume that's just how AI works.

It isn't. The missing piece is context. Memory Tune-Up runs a short, real
interview, about thirteen questions, that surfaces the things an AI needs to
stop being generic: your actual work, how you make decisions, the way you get in
your own way, what good work looks like to you, and what you're really building
toward. Then it helps you save that to memory, so every future conversation
starts with a real person instead of a blank one.

It's a tune-up, not a one-time setup. People change. The skill is built to be
run again every few months, updating what's already there.

## What's in this folder

- **`memory-tune-up.skill`** — the installable skill file. Use this if your AI
  environment supports skill uploads (see install instructions below).
- **`skill-source/SKILL.md`** — the same skill as plain text. Use this if you
  can't install a skill file, you can paste its contents into a project's
  instructions or into a chat.
- **`HOW-TO-USE.md`** — step-by-step setup and install instructions for both
  formats, plus how to run the interview.

## Quick start

1. Read `HOW-TO-USE.md`.
2. Install the skill, or paste the `SKILL.md` contents into your AI.
3. Tell your AI: "run memory-tune-up" or "do the memory interview with me."
4. Answer honestly. Set yourself a reminder to do it again in a few months.

## A note on the questions

They go a little deeper than people expect. That's the point. The payoff is
proportional to the honesty you bring.
